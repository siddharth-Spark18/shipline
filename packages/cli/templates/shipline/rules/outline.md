# Outline rules

<!-- Repo-specific instructions Claude must follow in the "outline" stage. Filled in by /shipline-setup; edit freely. -->

- Write `outline.md` with a `## Audience` heading and an `## Outline` heading (the stage can't finish without them, each with real text under it).
- Under Audience, say who will read this and what they already know. Name the docs it belongs with.
- Under Outline, list the headings of the new or changed pages and one line on what each covers.
- Read the existing docs first. Match their structure, tone, terminology and formatting, and link to related pages instead of repeating them.
- List the code, commands or behavior the docs describe, so the write stage can check them against the source.
- Don't write the docs yet. The developer confirms the outline first.
