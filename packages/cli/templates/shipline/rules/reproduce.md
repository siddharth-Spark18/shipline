# Reproduce rules

<!-- Repo-specific instructions Claude must follow in the "reproduce" stage. Filled in by /shipline-setup; edit freely. -->

- Write down the exact steps to trigger the bug, the expected result, the actual result, and the environment (version, branch, OS, data).
- Use a failing test when that is practical. Otherwise give a command or a sequence a person can repeat.
- Confirm you can reproduce it yourself before moving on. If you can't, say what you tried and ask the developer for more detail.
- Include error messages, logs and stack traces as they appeared, not paraphrased.
- Note how often it happens (always, sometimes) and any condition that makes it more or less likely.
- Don't change code to fix it in this stage.
