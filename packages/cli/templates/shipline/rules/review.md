# Review rules

<!-- Repo-specific instructions Claude must follow in the "review" stage. Filled in by /shipline-setup; edit freely. -->

- Write `review.md` with a `## Checklist` heading (the stage can't finish without it): each item from the outline checked against the final text.
- Read the changed pages as the audience would. Check accuracy against the code, then structure, then wording and spelling.
- Check the links, headings, code blocks and examples. Run the examples you can, and say which you could not run.
- Look at the final diff for leftovers: drafts, placeholder text, unrelated edits, and files outside the docs.
- Run any docs build or link check the repo has. If something fails, say so plainly.
- Don't commit or open a pull request until this stage is done.
