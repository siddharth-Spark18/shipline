# Write rules

<!-- Repo-specific instructions Claude must follow in the "write" stage. Filled in by /shipline-setup; edit freely. -->

- Follow `outline.md`. Write in the repo's existing docs style: headings, tone, terminology and examples.
- Edit documentation only (Markdown or MDX files, and the docs folder). Source files stay untouched, and Shipline blocks edits to them until this stage is done. If the docs need a code change, note it in `writing.md` instead of making it.
- Check every command, option, path and example against the code or by running it. Don't document behavior you haven't confirmed.
- Keep links working: update the table of contents or sidebar when pages are added, renamed or removed.
- Record in `writing.md` which pages changed, and anything you could not confirm.
- Don't commit or open a pull request in this stage.
